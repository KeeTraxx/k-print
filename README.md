# k-print
A Rust-based photo printing application.

## Overview
k-print is a photo printing application built with Rust, designed to provide a simple and efficient way to print your favorite photos on linux.

## Features
- Supports JPEG and PNG images.
- Allows for customizable print settings (paper size, orientation, etc.)
- Uses IPP (Internet Printing Protocol) to print
